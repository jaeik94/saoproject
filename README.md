# 아인크라드 전투 프로토타입 (1단계: 파티 전투)

Python 3.10+ (코어는 표준 라이브러리만, 분석 도구만 pandas). 모든 명령은 이 폴더에서 실행한다.

```
python -m app.gui                                   # 창 UI (적 종류·수, 솔로/파티, 정보 유무, 시드 선택)
python -m app.batch --n 200 --enemy dire_wolf --count 2   # 봇으로 여러 판 → logs/<폴더>/
python -m app.batch --n 200 --solo                  # loadout.json 한 명
#   --bot perfect(완벽 대처, --knowledge full 권장) | party(단순) | basic(평타만) | random
python -m analysis.summarize logs/<폴더>             # 배치 결과 요약
python -m app.frames --enemy dire_wolf              # 프레임표 + 방어 성공 후 반격 창 + 프리모션 끊기 가능 여부
python -m app.tiers --n 100                         # 적 등급 평가: data/tiers.json 기준표와 봇 결과를 나란히 (1:1, 3:1 × 완벽 대처/단순/평타 봇)
python -m unittest discover -s tests -t .           # 테스트 (결정론 포함)
```

## GUI 조작

- 차례인 아군은 무대에서 노란 테두리, 상태 목록과 타임라인에서 ▶로 표시된다. 결정 순서는 민첩 높은 순.
- **이동**: 무대의 초록 칸 클릭 (아군 칸은 지나갈 수 있지만 멈출 수 없고, 적 칸은 지나갈 수 없다).
- **행동**: 버튼 또는 숫자 키 1~9, 0. 버튼에 마우스를 올리면 타임라인 내 줄에 그 행동의 프레임이 그려지고, 공격이면 무대에서 대상 적이 강조된다.
- **적**: 굵은 화살표는 바라보는 방향, 적에서 아군으로 가는 선은 현재 대상 (주황 점선은 대상 전환 중). 붉은 칸은 장소 지정 공격의 영향 범위.
- **타임라인**: 정보 있음이면 적 줄에 앞으로의 반복 패턴이 옅은 색으로 이어진다 (방해받지 않을 때의 예측). 정보 없음이면 지금 예고만 보인다.

## 설정 파일

| 파일 | 내용 |
| --- | --- |
| `data/party.json` | 3인 파티 (멤버마다 loadout과 같은 형식) |
| `data/loadout.json` | 솔로 설정 |
| `data/enemies.json` | 적: 크기·차지 칸(footprint), 지능, 대응 태세, 반복 패턴, 포위 대응 공격 |
| `data/rules.json` | 무대·시작 칸, 헤이트, 대상 전환, 휴식 회복, 프렌들리 파이어, 하울, 지능(기억 길이) 계수 등 |
| `data/skills.json` `weapons.json` `armors.json` `items.json` `slot_skills.json` | 스킬·장비·아이템 |

**수치는 전부 임시값이다.** 오타 키는 로드 시 오류로 잡힌다 (`_`로 시작하는 키는 주석). Lv1 스탯(근력+민첩) 합은 10.

## 구현한 규칙 요약

- **육각 그리드**: 한 칸에 한 명, 적은 크기만큼 칸 차지 (1 / 3 / 7칸). 사거리는 칸 거리 (1 = 인접).
- **어그로**: 정면 헤이트(정면에 선 아군의 고정 헤이트) + 기억 길이 안의 누적 피해. 가장 큰 쪽이 대상.
- **대상 전환**: 방향 전환(적 속도로 증감)과 재로드(기억 중인 상대면 짧음)를 동시에 진행하고, 둘 다 끝나야 행동한다.
- **적 패턴**: 반복하는 공격 순서. 프리모션 중 끊긴 기술은 건너뛰고, 시작 전이던 예정은 그대로 이어진다. 대상이 바뀌면 다른 패턴을 처음부터.
- **적의 대응**: 적마다 쓸 수 있는 태세가 정해져 있다 (짐승형 1개, 소드 스킬 사용 2개, 고등급 3개). 사람 적응이 쌓일수록 자주 본 공격부터 "트리거"가 늘고, 트리거 공격의 프리모션을 보면 반응 시간 뒤 태세로 대응한다. 적응은 적의 태세 성공률도 올린다.
- **프렌들리 파이어**: 아군 기술 범위의 아군은 피해 절반, 행동 끊김(짧은 경직). 헤이트에는 영향 없음.
- **휴식**: 어그로 대상이 아니고, 행동 중이 아니며, 적과 인접하지 않으면 자연 회복. 포션은 그 속도를 일정 시간 높인다 (전열에서는 시간만 흐름). 솔로는 전투 중 회복 없음.
- **포위 대응**: 인접한 아군이 일정 수 이상이면 광역 공격을 먼저 쓴다. **하울**: 방패를 든 아군의 행동 (헤이트 증가 또는 다른 공격자 누적 피해 감소).
- 솔로 전투의 규칙(프레임, 태세·상성, 상쇄, 프리모션 끊기, 경직 감쇠, 무력화, 내구도, 무기 교체 재로드)은 그대로.

## 구조

| 폴더 | 역할 |
| --- | --- |
| `core/` | 전투 규칙. 파일·콘솔 의존 없음, 정수 틱(1프레임=100틱)·만분율, PCG32 난수. C# 이식 대상 |
| `app/` | 경계: 데이터 읽기, GUI, 봇, 배치 실행, 프레임표, 사건 → 문장 |
| `analysis/` | 로그 CSV 분석 (코어를 import하지 않음) |
| `tests/` | 결정론(같은 시드 = 같은 로그, 해시 시드 무관), 규칙 단위 테스트 |

`core/` 모듈: `rng` · `hexgrid`(육각 좌표) · `defs`(정의 데이터) · `loadout`(구성 검증) · `combatant`(전투 중 상태) ·
`formulas` · `ai`(적의 기억: 적응·트리거·누적 피해·재로드) · `battle`(이벤트 큐 엔진, 패턴·헤이트) · `preview`(결정 요청·타임라인) · `log`.
